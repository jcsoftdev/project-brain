# Usability

Does the interface let a person complete the product's primary flows without confusion, and does it tell them what happened when something goes wrong? Gate: browser observation ran (`browser.md`), and a UI framework or HTML entry point was detected. Findings here are `observed` when they cite a bundle artefact, `read` when they cite source, and never above those ceilings.

## Feedback and visibility of state

- [ ] Every step in `steps.md` that changes state shows a visible response within the same step — `Read` the step's screenshot and console line; a click with no rendered change and no pending indicator is a silent action.

## Out of static reach

- Whether real users complete the flow; a single walked run proves the path exists, not that people find it.

## Severity guidance

| Situation | Severity |
|---|---|
| Primary flow step produces no visible feedback | Medium |
